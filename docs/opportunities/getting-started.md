# Internships & entry-level: start here

Explore real opportunities before deciding which title to pursue. This U.S. collection is for current students, recent graduates, and people moving into AI from another career.

## Choose your starting point

| Your situation | Start with | First question |
| --- | --- | --- |
| Current undergraduate | Internships and co-ops | Must I return to school, and can I commit to the dates? |
| Master's / PhD student | Graduate-eligible internships and degree-alternative full-time roles | Is my degree level and graduation date eligible? |
| Recent graduate | Explicit new-grad or no-professional-experience roles | Is there a graduation window or prior-internship requirement? |
| Career changer with engineering experience | Early-career and selected mid-level examples | Does my existing production experience satisfy the requirement? |
| Career changer without coding experience | Foundations, then a small project | Can I build, test, and explain a working application? |

These are navigation suggestions. Being a student, graduate, or career changer does not itself establish eligibility for a posting.

## Do not equate “junior” with “no experience”

[Valtech's junior example](./entry-level.md#valtech-junior) asks for 2–4 professional years. [NewsBreak's ML infrastructure example](./entry-level.md#newsbreak-ml-infra) provides different bachelor's and advanced-degree routes. They remain in the early-career collection with prominent caveats.

Internships vary too: some ask for advanced degrees or previous internships. Check the requirements, not only the program name.

## Turn a requirement into evidence

| Requirement you see | Evidence you could develop — our advice |
| --- | --- |
| Python / APIs | A small service with validation, tests, error handling, and reproducible setup |
| Retrieval / grounding | A document assistant with source citations and unsupported-question tests |
| Agent tool use | A mock workflow with bounded permissions, retries, and approval points |
| Evaluation | A held-out test set, rubric, baseline, and failure analysis |
| Stakeholder communication | A short requirements brief, user demo, and feedback-driven revision |
| Production ownership | Deployment notes, monitoring, rollback plan, and measured limitations |

Projects can demonstrate skills; they do not replace an explicit degree, enrollment, authorization, or experience requirement.

## Before you apply

Open the original posting. Confirm it is still accepting applications, check dates and location, separate required from preferred skills, and ask about unclear work-authorization or sponsorship details. Use the [job research worksheet](../job-research.md).

Then choose a [learning path](../learning-path.md) that fits your starting point and one [portfolio experiment](../portfolio.md). The collection is a dated snapshot, not a live vacancy feed.
