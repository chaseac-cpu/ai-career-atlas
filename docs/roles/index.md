# Compare AI career paths

Choose the work you want to own. These broad families are not standardized industry definitions. “Emerging” includes established roles whose scope is changing with AI.

| Role | Focus | Skills to investigate |
| --- | --- | --- |
| [Forward Deployed Engineer](./forward-deployed-engineer.md) | Customer delivery | Software development, LLM integration, evaluation, communication |
| [AI / Applied AI Engineer](./ai-engineer.md) | Product engineering | Python or TypeScript, APIs, retrieval, tool calling, evaluation |
| [AI Solutions Architect](./solutions-architect.md) | Technical design | System design, cloud, discovery, security, communication |
| [AI Evaluation Engineer](./evaluation-engineer.md) | Measurement | Python, datasets, experimental design, statistics, error analysis |
| [Machine Learning Engineer](./ml-engineer.md) | Model lifecycle | Python, ML fundamentals, data pipelines, experiment tracking |
| [AI Security Engineer](./security-engineer.md) | System defense | Application security, threat modeling, authorization, adversarial testing |
| [AI Product Manager](./product-manager.md) | Product direction | Discovery, analytics, experimentation, AI limitations, prioritization |
| [Agent / Automation Engineer](./agent-engineer.md) | Workflow automation | APIs, workflow design, state management, evaluation, observability |
