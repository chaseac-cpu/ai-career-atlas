# AI Security Engineer

<div class="research-note">System defense · Role field guide</div>

Investigate misuse of AI applications and design controls around data access and tools.

## What the work looks like

This is our broad role synthesis. Scope depends on the team, seniority, and employer. Ask for a recent project example before assuming a title describes the job.

**Skills to practice:** Application security, threat modeling, authorization, adversarial testing.

## Portfolio experiment

Test a local mock agent for prompt injection and excessive tool permissions. Measure defenses in your own sandbox.

Include a demo, reproducible setup, measured results, and a failure analysis. This is a suggested practice project, not an employer hiring requirement.

## Interview questions

Is the scope application security, model safety, infrastructure, or incident response?
