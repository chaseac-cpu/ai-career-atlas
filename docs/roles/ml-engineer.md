# Machine Learning Engineer

<div class="research-note">Model lifecycle · Role field guide</div>

Develop and operate systems that learn from data, including training, serving, and monitoring.

## What the work looks like

This is our broad role synthesis. Scope depends on the team, seniority, and employer. Ask for a recent project example before assuming a title describes the job.

**Skills to practice:** Python, ML fundamentals, data pipelines, experiment tracking.

## Portfolio experiment

Train a small classifier, compare a simple baseline, test on held-out data, and propose drift monitoring.

Include a demo, reproducible setup, measured results, and a failure analysis. This is a suggested practice project, not an employer hiring requirement.

## Interview questions

Is the emphasis training, infrastructure, ranking, or integration?
