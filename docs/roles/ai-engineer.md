# AI / Applied AI Engineer

<div class="research-note">Product engineering · Role field guide</div>

Turn model capabilities into useful software features and reliable application workflows.

## What the work looks like

This is our broad role synthesis. Scope depends on the team, seniority, and employer. Ask for a recent project example before assuming a title describes the job.

**Skills to practice:** Python or TypeScript, APIs, retrieval, tool calling, evaluation.

## Portfolio experiment

Build a document assistant with citations, unsupported-question handling, and a quality benchmark.

Include a demo, reproducible setup, measured results, and a failure analysis. This is a suggested practice project, not an employer hiring requirement.

## Interview questions

Does the team use existing models or train them? Who owns evaluation?
