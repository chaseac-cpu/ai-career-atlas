## A job title is only the starting point

An AI Engineer may build a product feature. A Forward Deployed Engineer may work inside a customer's business. An Evaluation Engineer may measure whether either system works. Start with the work you want to own, then investigate the employer's version of the role.

New to the field? Start with [internships and entry-level opportunities](./opportunities/getting-started.md), [compare eight role families](./roles/index.md), then choose a [portfolio experiment](./portfolio.md).

## Real descriptions, useful distinctions

Explore **22 U.S. examples across 18 employers**: seven internships/co-ops, seven entry-level or early-career jobs, four mid-level examples, and four senior/staff examples. Each includes a dated original source, level evidence, eligibility, pay context, and a suggested way to demonstrate the work.
